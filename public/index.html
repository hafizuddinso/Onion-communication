A working study of secure communication over onion routing.

I built Onion Communication as part of my Master's thesis, Framework for Safe Communication in the Non-Indexed Web (Hidden Web). The purpose was practical: build the communication path, add application-layer cryptography, and use the prototype to examine how the pieces behave together.

This site is the research interface and test environment. It is not presented as a replacement for Tor or as a production messenger.

01

What is being tested

Onion transport

The service can be reached through a Tor v3 onion address, keeping the network route separate from the public web presentation.

Application encryption

The prototype includes AES-GCM and ECDH-oriented experimental workspaces so encryption and key-establishment operations can be studied alongside the communication interface.

System behaviour

The implementation gives me a concrete baseline for examining security, anonymity, resilience and the cost of cryptographic operations in an anonymous communication system.

From the MSc prototype to the next research question.

The present system uses classical cryptographic mechanisms. My next research direction is the transition toward post-quantum secure anonymous communication and onion-routing architectures, including the security and performance trade-offs introduced by that transition.
